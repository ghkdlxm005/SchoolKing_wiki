## 1. Dustpan 뷰모델 "축 고정" 버그 (핵심)

- **증상**: 쓰레받이가 손에 박힌 채, 애니를 재생해도 회전(축 이동)하지 않음. 사용자가 리그·애니는 다 맞춰뒀고 "코드의 무언가" 때문이라고 지목.
- **진단 경위**: 처음엔 애니 코드로 포즈를 잡으려다(강제 IdleAnim·마지막 프레임 freeze·달리기 시퀀스) 오히려 리그 기본 포즈를 덮어써서 헤맴 → 전부 원복해도 여전히 박힘 → **애니가 아니라 리그 조인트가 잠긴 것**으로 방향 전환. Compass(정상 무기)와 비교: Compass는 idle 애니 없이 리그 기본 포즈로 잘 잡힘 → Dustpan도 리그 기본이 정상이어야 하는데 축이 안 움직임.
- **원인 두 가지** (둘 다 핸들러/config가 사용자의 **새 축 리그**(Right Main/Left Main Weld 구조)를 지원 못 한 것):
  1. `MeleeConfig.Default.ArmWeldMap`이 쓰레받이(handle·brush·body·rubber)를 **팔에 직접 WeldConstraint**로 붙임. 새 축 리그와 충돌해 축을 잠금.
  2. `ClientHandler.setupViewmodel()`의 자동 weld가 "rigged(이미 조인트로 연결됨)" 판정을 **Motor6D만** 검사 → Weld로 축에 붙은 쓰레받이 파트를 "안 붙음"으로 오판하고 **HRP에 재고정**.
- **변경 위치**:
  - `MeleeConfig` Dustpan 항목에 `ArmWeldMap = {}` override(팔 직접 용접 제거).
  - `ClientHandler.setupViewmodel()` rigged 판정에 `Weld`/`WeldConstraint` 포함.
- **검증**(Play): 쓰레받이 파트가 Right Main/Left Main(축)에만 연결됨 확인, 들기·공격·재생·슬라이딩 재생 시 Right Main `Transform` 변화(축 회전) 확인.

## 2. Dustpan 상태별 애니메이션

- **Idle**: 리그 기본 포즈(애니 미재생). 사용자가 리깅한 기본 포즈가 파지 포즈이므로 강제 애니를 얹지 않음.
- **장착**: 들기(70934603796055) 1회 재생 후 기본 복귀.
- **공격**: 좌클릭 스윙에 공격(134776635996855) 연결, **2배속**.
- **달리기 진입**: 재생(71609837264681) 1회 → 1프레임(92638375107608, 무기 내림) 유지. 재생 **1.5배속**(초기 1.8 → 사용자 요청으로 1.5).
- **슬라이딩**: 슬라이딩(81035765089543) 재생 후 마지막 프레임 유지(슬라이딩이 달리기보다 우선).
- **달리기 복귀 규칙**: 슬라이딩 후 복귀(IsRunning 전환) 및 공격 후 달리기 중이면 재생 재적용.
- **변경 위치**: `MeleeConfig` Dustpan 애니 ID, `ClientHandler`의 `AnimMap`/`AnimSettings` + `playRunSeq`/`playSlide` + `startRunWatch`(IsRunning/IsSliding 워처) + `trySwing`(공격 후 재생 복귀).
- **한계**: 지속 달리기·전환 타이밍은 Studio에서 실제 Shift 입력이 막혀(SlideScript가 강제 세팅한 IsRunning을 즉시 되돌림) 라이브 검증 필요. 재생·공격·슬라이딩의 축 이동은 격리 검증됨.

## 3. 근접무기(슬롯3) 이동속도 보너스

- **요구**: 근접무기 장착 시 기본이속 +3, 달리기 +3, 슬라이딩은 비례.
- **로직**(`SlideScript`): `meleeSpeedBonus()` = 장착 Tool에 `MeleeName` 있으면 3, 아니면 0.
  - 걷기/달리기: `targetSpeedFor`의 base에 `+ meleeSpeedBonus()` → 걷기 16→19, 달리기 24→27(맨손 달리기 +3과 동일. Tool 있으면 맨손 +3 로직은 스킵되어 중복 없음).
  - 슬라이딩(비례): `slideSpeed`에 `+ SlideForce × (meleeSpeedBonus/RunSpeed)` = 50×(3/24) ≈ +6.25 (달리기 +12.5%와 동일 비율).
  - 툴 장착/해제 시 `Character.ChildAdded/ChildRemoved`(Tool) 훅으로 이속 즉시 재적용.
- **검증**(Play): 맨손 걷기 16, 근접 장착 걷기 19, 해제 16 확인. 달리기 27·슬라이딩 비례는 실제 달리기 입력 필요로 라이브 검증 대기.
