## 사람이 구조화해 전달 (Human)

- **증상 우선, 원인은 AI에게**: "상대 달리기 소리 템포가 내 것과 다르다. 근데 AI(봇)가 남에게 들려주는 소리는 내 것과 같더라. AI 방식을 상대에게 적용해라." — 관찰(봇은 맞고 상대는 틀림)로 해법 방향을 지목.
- **밸런스 수치 직접 지정**: 컴퍼스 +50%·탄퍼짐 1.5배 → 이후 "너무 빠름, 0.075로". 실리콘건 최대 13, 유리벽 2배.
- **의도 정정**: 토스터 3단 차징을 파티클로 만들었더니 "그거 만들라는 게 아니라, 1인칭 뷰모델/리그를 그대로 남에게 보이게 해라" — 접근 자체를 재지시.
- **동등 취급 규칙**: "봇 = 플레이어" — 봇 발사도 플레이어와 동일하게 총알·빵·펠릿 노출.
- **로드아웃 스펙 명세**: "진입 시 공격 1 + 투척 1만 고른다. Dustpan은 전원 지급, 3번 키. 나중에 다른 맨손 무기 추가 예정."
- **UI 피드백**: 새로 만든 로드아웃 패널에 "레이아웃 별로임, 기존 레이아웃 들고와" + "이 상태에서 마우스 안 움직임."

## Claude 구현·디버깅 (AI)

- **상대 달리기 소리** — 원인: 상대의 `IsRunState`/`IsCrouching` 어트리뷰트가 **클라 간 복제되지 않아** 상대는 항상 `gym_walking`(걷기)로 재생. 봇은 속도 기반(vel>3→달리기)이라 본인과 동일하게 들렸음. → 상대 플레이어도 봇처럼 **속도 기반**(수평속도 20 초과→달리기, 걷기16/달리기24 기준)으로 판정하도록 `computeState`에 `useVel` 분기 추가. 본인은 로컬 어트리뷰트가 정확하므로 유지.
- **무기 밸런스** — GunConfig: 컴퍼스 FireRate 0.045→0.03(후 0.075)·Spread 0.009→0.0135, 실리콘건 LaserMaxDmg 12→13. 유리벽 2배는 SiliconGun ServerHandler에 이미 존재 확인.
- **Dustpan** — ①유리벽 원샷: 스윙 범위 내 `glass wall` 모델의 Humanoid Health를 0으로(GlassWallSystem이 HealthChanged로 파괴), 유리벽은 적 타겟에서 제외. ②락온/범위 일치: MeleeLunge 콘 55°→120°(사거리 11=스윙 범위). ③넉백: MeleeConfig.Dustpan `HitKnockback` 55→100.
- **에너지드링크** — MonsterEnergySystem: 기존 7개 상시 노출 → 스포너(최대 4개 동시, 랜덤 위치, 소진 시 재충원). 도핑(`Ability` 어트리뷰트) 중엔 획득 가드.
- **토스터 총알/빵 상대 노출** — 총알은 클라 전용 `ToasterBullet`이라 상대에겐 안 보였음. 서버 GunFire broadcast에 펠릿 방향 전체(`pelletDirs`)를 실어, 상대 클라(`WeaponEffectsClient`)가 실제 `ToasterBullet` 9발 스폰 + 빵(`ToasterVM.bread_1`) 팝. **속도 5000→700 + 최소 비행 0.12초 + Trail**로 가시성 확보(빠른 총알이 1프레임에 지나가 안 보이던 것 수정). 봇 발사도 동일 펠릿 broadcast.
- **토스터 3인칭 리그·애니** — `r15 toaster` 리그를 WeaponRig3P로 부착, 3인칭 애니(대기·들기·사격·점프·재장전·앉기·앉기걷기·슬라이딩) 연결 + Heartbeat pose 스위처.
- **토스터 3단 차징 실제 메시** — 파티클 방식 폐기. 발사자가 단계를 `ToasterChargeEvent`로 전송 → 서버 릴레이 → 상대 클라가 뷰모델 `ToastStage2`(구운빵)/`ToastStage3`(탄빵+불) 메시를 리그 빵 위치에 복제·단계별 표시.
- **모든 총알 궤적** — `drawTracer`에 Dustpan식 Trail 추가(Lifetime 0.8s, 폭 테이퍼). 잠깐 남았다 소멸.
- **로드아웃 선택 게이트** — `LoadoutSystem`(신설): 라운드 시작 시 15초 대기(전원 Ready 또는 초과), 확정 시 공격+투척+Dustpan만 지급, 리스폰 재적용. `CapturePointSystem` freeze 직후 호출. **UI는 별도 패널을 만들었다가 피드백 받고 기존 로드아웃 메뉴(loadoutGui) 재사용**으로 전환 — Ready+타이머 오버레이만 얹고, `MenuOpen` 어트리뷰트로 카메라가 마우스를 풀도록(마우스 잠김 수정). 키 1=공격/2=투척/3=Dustpan.
- **매칭 수락 팝업** — `MatchmakingService` 폴러에서 텔레포트 직전 `state="accept"` + 10초 대기(`MatchAcceptEvent`). 수락 시 텔레포트, 미수락 시 로비 잔류. `MainMenuController`에 MATCH FOUND 팝업. **게시 서버에서만 실동작**(Studio는 로컬 폴백) → 실기 검증 필요.
- **버그 2건** — [BUG-0028](../bugs/BUG-0028-meleehitevent-missing.md) `MeleeHitEvent` 미존재로 근접 넉백 무효(RemoteEvent 생성). [BUG-0029](../bugs/BUG-0029-slidescript-forward-decl-nil.md) SlideScript `cleanupAll`이 뒤에 정의된 `targetSpeedFor` 참조 시 nil(포워드 선언 추가).

## AI 봇(CleanUP) 개선 — 10~25차 (08-06~07 연속 작업)

봇을 플레이어와 완전히 동일한 룰로 움직이는 것이 목표("봇 = 플레이어"). BotManager 중심으로 25차까지 반복 개선.

### 인지·전투
- **인지 파이프라인**: 정면 120도 부채꼴(25스터드 내 청각은 360도) → 0.5초 유지 시 락온, 20스터드 내 즉시 락온, 3초 미확인 시 해제. 락온 시 머리 위 빨간 느낌표(맵 비투과).
- **피격 반격**: 맞으면 공격자(플레이어·봇)를 각도·연막 무시 즉시 락온.
- **연막 룰 동일**: 시선 선분이 활성 연기 구를 지나면 인지 불가. 연막 발견 시 투척무기 견제.
- **전투 이동**: 매 틱 좌우 스트레이프(연속 이동) + 전투 슬라이딩, 점프는 드물게(3%). 대상 주시(뒤 보고 쏘기 방지).
- **무기 4종 실사용**(목발·컴퍼스·실리콘건·토스터): 실제 GunConfig 탄창·연사·재장전 준수. 토스터는 실제 3×3 펠릿 판정(맞은 수 × 8뎀) + **원거리(40+) 3단 차징**(차징 토스트가 상대에게 표시, 차지샷 사거리 264). 실리콘건 봇은 높은 지점 선점 성향.
- **투척**: CAN·Cup 랜덤, 투척 순간 실제 툴 스왑(리깅 동일), 효과 플레이어와 동일(CAN 95→40 감쇠+넉백, Cup 7초 장판 DOT).

### 이동·맵 활용
- **이동 우선순위(25차)**: 장판 회피 > **거점 진입(최우선)** > 락온 추격(거점 70 제한) > 거점 내 로밍.
- **거점 내부**: 적(플레이어·봇)이 거점 부근에 있으면 그 위치로 계속 수색 이동. 존버 금지(5초 정체 시 강제 이동), 로밍 반경 = 거점 전체.
- **맵 상호작용**: 문 열기(hinge 트윈, 플레이어 E와 동일), 유리벽 파괴, Rope 집라인 탑승, 사다리·리프트·점프대 수직 우회, 에너지드링크 획득.
- **벽 비비기 해소**: 수직 우회 2초 무진전 시 포기, 경로 실패 확정 시에만 목표 폐기(계산 중 대기), 실패 중에도 직진 유지.
- **스폰**: 모든 플레이어·봇으로부터 최소거리가 가장 큰 SpawnLocation 선택(몰림·끼임 방지).

### 아이템·리깅·사운드
- 기본 소지 플레이어 동일(수류탄 2·책 3). 비전투 시 책으로 쉴드 +50, 사망 시 책 드롭, 바닥 책 루팅.
- 3인칭 무기 리깅·애니 전 무기 동일(WeaponRig3P + ThirdPerson 애니 + pose 스위처 + Tilt). 장착 레이스 대비 rig defer 안전장치.
- 발소리·달리기 소리 로직 플레이어와 동일(속도 기반), 사망 시 정지.
- 봇 처치 시 킬러캠(DeathCam killerBot), 봇 킬 점수(기본 20·거점 내 50·연속 30).
