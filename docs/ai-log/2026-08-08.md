- **요구**: "AI 동선을 데이터로 깎고 싶다. 학습시켜 쓰고 싶다. 지금 버전은 그대로."

  - **DataStore 영구화**: 매치 종료·서버 종료 시 요약본(히트맵 16셀·사망·루트·봇 통계·점수)을 `AIMovement_v1`에 저장, `index` 키로 최근 60개 관리. **Studio는 기본 쓰기 금지**(검증 시에만 TelemetryStudioWrite=true), 샘플 20개 미만 세션 저장 안 함(노이즈 컷). 게시 후에는 개발자 PC 꺼져 있어도 클라우드에 자동 축적.
  - **첫 성과(34차)**: 봇 1기 정체율 74%·한 셀 90회 데이터 → 조사 결과 로프(Rope_act Y=36) 하단이 VERTS에 등록돼 "공중의 도달 불가 목표 접근→포기→재선택" 무한 루프. 로프 끝 VERTS 등록 제거 + 수직 우회 정체 포기 시 해당 목표 10초 블랙리스트(유사 끼임 전반 방어). 재측정: 정체율 74%→30%.
  - **첫 학습 사이클**: 실서버 세션(517점 매치 포함)에서 진입 루트 6개 추출 → 품질 게이트(완주+길이 25+·우회율<2.5) 통과 2개를 `ServerStorage.RouteLibrary` v1로 저장. **봇은 아직 미사용** — 10~20개 축적 후 ε-greedy(20% 탐험)로 연결, 품질 게이트+버전 롤백으로 퇴화 방지, 유사 루트 중복 제거+사용 편중 감쇠로 단일화 방지.
- **운영**: 재게시해도 DataStore 데이터는 유지(클라우드, 실험 단위). 날아가는 건 진행 중 서버 메모리의 미저장분뿐.
