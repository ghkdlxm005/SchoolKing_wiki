# 2026-08-10 — AI 개발 로그

| 항목 | 값 |
| --- | --- |
| 개발 항목 | AI 봇 전투 다중화(무기 성향 + mood + 스폰 분산 + 위층 캠퍼 추격) · 학습 데이터 시각화(탑다운 뷰어) |
| 설계 논의 | "이기는 봇 ≠ 재밌는 봇" — 승리 최적화는 캠핑/존버로 수렴. 목표를 "능동적 교전 생성"으로 재정의. 학습은 이동에만, 전투는 손설계 + 데이터는 조율. |

## 1. 설계 배경 — 개싸움·캠퍼 문제

- **관찰(사용자)**: ①봇끼리 개싸움만 하고 플레이어는 킬 줍줍(방관) ②2·3층 캠퍼를 못 잡음 ③무기별 이점을 못 씀(전부 똑같이 붙어 쏨).
- **원인 진단**:
  - `acquire()`가 "가장 가까운 적"만 봐서 봇끼리 엉킴(플레이어 우선 개념 없음).
  - 최근 "거점 점수 최우선"으로 추격을 거점+15로 조여 거점 밖 캠퍼 방치.
  - 무기 무관 KeepDist 18 고정 — 무기 개성 전무.
- **방향 합의**: 승리가 아니라 **능동적 교전**을 목표로. 무기 성향(기본기) + mood(변주)의 2단 구조. FFA 우선, 팀전은 나중에 협동 레이어를 위에 얹음(개인 성향 재작성 불필요).

## 2. 무기 성향 프로파일 (42차 A)

- `CFG.Profiles`: 무기별 교전 거리·역할·고지 선호.
  | 무기 | 역할 | 거리 | 고지 |
  |---|---|---|---|
  | Toaster | brawler | 9 | X |
  | SiliconGun | sniper | 32 | O |
  | Compass | skirmisher | 17 | X |
  | LegCrutch | duelist | 15 | X |
- `equipWeapon()`: 스폰 시 `BotRole`/`BotEngage`/`BotHigh` 어트리뷰트 세팅.
- **스폰 무기 분산**: 살아있는 다른 봇이 안 든 무기 우선 선택 → 한 판에 4성향 다양화(기존엔 토스터 3마리 같은 중복 발생).

## 3. mood 시스템 (42차 B)

- 매 틱 산출(`st.mood`, `BotMood` 어트리뷰트):
  - **cautious**: HP<40% 또는 (쉴드0 & HP<65%) 또는 재장전 중 → 물러나 정비.
  - **aggressive**: 연속킬 2+ / 상대 쉴드0·저체력 / 내 HP>70% → 밀어붙임.
  - **neutral**: 기본.
- 연속킬(`st.streak`): Kill 멈블 트리거에서 +1, 8초 무킬 시 리셋.
- mood가 교전 거리를 변조: 공격 ×0.6(접근), 신중 ×1.7(후퇴).

## 4. 역할·mood 교전 포지셔닝 (42차 C)

- 전투 이동을 한 곳(주시 블록, Spot A)으로 통합, 무빙샷 블록(Spot B)에서 이동 제거(속도·점프만) — 충돌 방지.
- 로직: 유효거리 = `BotEngage` × mood 배율.
  - 대상이 Y+8 위 → `followPath`로 등반(**위층 캠퍼 추격** — 사다리·리프트 경유).
  - dist > eng+5 → 접근(러시).
  - dist < eng-5 → **카이팅**(뒤로 빠지며 좌우, 스나이퍼·신중 mood 핵심).
  - 그 사이 → 좌우 스트레이프 유지.
- 기존 "쉴드 파괴 즉시 접근"은 aggressive mood(상대 쉴드0 → eng×0.6)로 자연 흡수.

## 5. 검증

- Play(봇 3기): 무기 중복 종류 0(완전 분산), 역할·거리·mood 정상 세팅, 에러 0.
- 격리: **스나이퍼 카이팅** 거리 15→21(후퇴), **브롤러 러시** 24→16(접근) — 방향 정반대 확인. 무기별로 확실히 다르게 놈.

## 6. 학습 데이터 탑다운 뷰어 (별도)

- DataStore 30세션에서 맵 지오메트리·히트맵(봇/플레이어)·사망 411·학습 루트 10을 추출 → Claude 인터랙티브 위젯(2D 탑다운, 레이어 토글·루트 재생). 관찰: **B 스폰(-247,-235)발 학습 루트 0개**(품질 게이트 통과 표본 없음 — B 표본 부족).

## 7. 사다리 등반 수정 (43차)

- **증상**: 봇이 사다리를 못 탐(학습 후속 확인).
- **진단**: 겹쳐 놓으면 등반 정상(Climbing 진입, Y4→11) → 등반 메커니즘은 멀쩡, **접근 위치가 문제**. 수직 우회가 트러스 **앞 2스터드 지점**을 목표로 잡아 허공에서 제자리걸음.
- **수정**(`BotManager`): 사다리 VERTS base를 **트러스 중심**으로(올라타서 자동등반) + 등반 중 위 방향 입력 + 진행도 판정에 **높이 상승도 진전 인정**(등반 중 flat 안 줄어도 포기 안 함).
- **검증**: 봇 바닥 Y5 → 사다리 타고 상단 Y12 도달·Climbing 진입, 실전 28초 상단 정체 0초·에러 0.

## 8. 피격 반격 — 사거리 무관 대응 (44차)

- **요구**: "사거리 상관없이 맞으면, 유효 데미지 넣을 수 있으면 반격 / 아니면 엄폐 후 반격."
- **로직**(`BotManager`): 피격 시 `st.revengeUntil`(6초) 기록. 반격 이동 브랜치(장판 이탈 다음, 거점 진입보다 우선): 공격자가 **교전 사거리 90 밖 or 시야 없음**(=지금 유효 데미지 불가)이면 `followPath`로 공격자에게 **엄폐 접근**(경로탐색이 엄폐 활용), 사거리·시야 확보되면 전투 로직이 반격. 반격 추격은 거점 제한 무시(거점+120까지 — 저격/캠퍼 대응).
- **검증**: 사거리밖 저격(122)→접근(53), 사거리안 피격(25)→교전 유지(도망 X), 에러 0. (43차 위층 추격과 합쳐 캠퍼 두 유형 대응: 위층=사다리 등반, 원거리=엄폐 접근)

## 9. 킬 피드백 중앙 팝업 (MW3 스타일)

- **요구**: 킬 점수가 랭킹 바 옆에 작아 안 보임 → MW3처럼 조준점 위 큼직하게.
- **구현**(`ScoreHUD`): KillFeedback 레이어 — 킬 시 화면 중앙(0.38, 조준점 위)에 큰 +점수(56pt, 검은 외곽선) 팝인 스케일 → 위로 떠오르며 페이드. 사유(ELIMINATED / ZONE KILL / KILL STREAK xN), 연속킬 금색, 빠른 연속 킬은 위로 스택. 기존 랭킹 바 점수·거점 +점수는 유지.
- **검증**: +20/ELIMINATED·+80/KILL STREAK x3(금색) 중앙 렌더·스택.

## 10. 매칭 안정화 + 점수판 정렬 (6건)
