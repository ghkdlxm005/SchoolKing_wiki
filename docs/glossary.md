# 용어

| 용어 | 뜻 |
| --- | --- |
| 실드 | 체력 위에 덧대는 보호막(100). 먼저 깎이고 책으로만 회복 |
| 왕관 | 왕관 뺏기의 핵심 아이템. 최대 체력 125, 위치 공개 |
| 왕관 탈환 | 떨어진 왕관을 다음에 주워 +150점 |
| 거점 | 맵 중앙 구역. 왕관 보유자가 머물러야 하는 곳 |
| 도움 | 막타는 아니지만 최근 10초 안에 피해를 준 처치 기여. 피해 비율만큼 점수 |
| 킬캠 | 사망 후 나를 처치한 상대 시점 화면 |
| 차지 | 토스터 우클릭 유지로 산탄을 모으는 것 |
| 화상 | 토스터 완충 사격으로 거는 실드 지속 피해 |
| 탄 합치기 | 스나이퍼 남은 탄을 1발로 합친 강화탄 |
| 점프 피로 | 연속 점프 시 높이가 줄어드는 효과 |
| TTK | 교전 시작부터 처치까지 걸리는 시간 |
