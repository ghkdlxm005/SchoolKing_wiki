# School KING

**School KING**은 학교를 배경으로 한 Roblox **아레나 무브먼트 슈터**입니다. 목발, 컴퍼스, 토스터 같은 학교 물건이 무기가 되고, 슬라이딩·벽 타기·그래플링 훅으로 빠르게 움직이며 싸웁니다.

:::info 테스트 중
현재 테스트 빌드 기준입니다. 수치와 규칙은 업데이트로 바뀔 수 있고, 바뀐 내용은 [패치 노트](/patch-notes)에 올라옵니다.
:::

## 처음 하는 법
1. 로비에서 모드와 대전 방식(AI / PvP)을 고릅니다. → [로비](./modes/lobby.md)
2. 경기 시작 전 **무기 선택** 화면에서 주무기 1개와 투척 무기 1개를 고릅니다. 근접 무기 쓰레받이는 모두 기본 지급. → [무기](./weapons/index.md)
3. 체력 100 + 실드 100으로 시작합니다. 실드는 **책**으로만 회복되니 아껴 쓰세요. → [체력·실드](./health.md)
4. <kbd>Shift</kbd>로 달리고 달리는 중 <kbd>Ctrl</kbd>로 슬라이드. → [이동](./movement.md) · [조작키](./controls.md)
