# 변경 이력 (Changelog)

코드·시스템·문서의 **의미 있는 변경**을 최신순으로 기록한다. 핵심은 **무엇을 / 왜** 바꿨는지다.

> 자동 기록: 각 문서 하단의 **"마지막 수정"** 날짜는 Git 이력에서 자동으로 표시된다(누가·언제).
> 이 페이지는 그중 **굵직한 변경**만 사람이 골라 남기는 곳이다.

## 작성 규칙 (26.08.08 역할 정리)

- 이 페이지는 **간단한 패치 노트**: 한 항목 = 2~4문장(무엇을/왜 + 핵심 수치). 길게 쓰지 않는다.
- **세부 내용**(수정 스크립트·함수 위치, 원인 분석, 검증 과정·실측 수치, 의사결정 경위)은 날짜별 [ai-log](./ai-log/index.md)에 **항목별 섹션**으로 기록한다.
- 큰 변경은 [기능](./features/index.md)·[버그](./bugs/index.md) 문서를 만들고 양쪽에서 링크.
