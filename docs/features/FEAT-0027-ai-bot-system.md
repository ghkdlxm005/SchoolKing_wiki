## 핵심 원칙 — 봇 = 플레이어

봇은 별도 간이 로직이 아니라 **플레이어와 동일한 시스템을 그대로 탄다**. 무기는 실제 Tool을 들고(3인칭 리깅·애니), 수류탄은 플레이어 파이프라인(`GrenadeCore`)으로 던지고, 힐은 플레이어 힐 세션(리그·지퍼 소리·0.9초/권), 발소리·사망 룰·킬 점수·킬러캠까지 같다. "봇만 유리/불리"한 예외는 버그로 취급한다.

## 인지 (Perception)

| 요소 | 값 |
| --- | --- |
| 시야 범위 | 120 스터드 |
| 정면 인식 | 120도 부채꼴 (dot ≥ 0.5) |
| 청각 | 25 스터드 내는 각도 무시 |
| 락온 | 0.5초 유지 시 락, 20 내는 즉시 락, 3초 미확인 시 해제 |
| 피격 반격 | 맞으면 공격자(플레이어·봇)를 각도·연막 무시 즉시 락(6초) |
| 연막 차단 | 시선 선분이 활성 연막 **바운딩 구**를 지나면 인지 불가 |
| 은신 | Stealth 대상은 못 봄(플레이어 동일) |
| 표시 | 락온 시 머리 위 빨간 `!`(맵 비투과) |

## 전투 성향 (42차 — 무기별 + mood)

무기가 **기본 성향**(교전 거리·역할)을 정하고, **mood**가 상황별로 변주한다.

| 무기 | 역할 | 교전 거리 | 특징 |
| --- | --- | --- | --- |
| Toaster | 브롤러 | 9 | 바짝 붙어 러시 |
| SiliconGun | 스나이퍼 | 32 | 고지 선점 + 카이팅(가까우면 후퇴), 슬로우 |
| Compass | 스키미셔 | 17 | 중거리 피크·스트레이프 |
| LegCrutch | 듀얼리스트 | 15 | 유연 |

**mood** (매 틱 산출): `aggressive`(연속킬·상대 약함·HP 높음 → 거리 ×0.6 접근), `cautious`(HP<40%·쉴드0·재장전 → 거리 ×1.7 후퇴·힐), `neutral`(기본).

**포지셔닝**: 유효거리 = 무기거리 × mood배율. 대상이 Y+8 위면 followPath로 등반(위층 캠퍼 추격), 멀면 접근, 가까우면 카이팅, 그 사이는 스트레이프. **스폰 시 무기 분산**(한 판에 4성향 다양화).

**피격 반격(사거리 무관)**: 맞으면 6초간 공격자 대응. 유효 데미지 가능(사거리 90 내 + 시야)이면 그 자리서 반격(도망 X), 불가능(멀거나 안 보임)이면 공격자에게 **엄폐 접근 후 반격**(경로탐색이 엄폐 활용, 거점+120까지 추격). 위층 캠퍼는 사다리 등반으로, 원거리 저격수는 엄폐 접근으로 대응.

## 사격·명중

- 실제 무기 Tool 사용. 탄창·연사·재장전은 GunConfig 그대로(플레이어 동일).
- 고정 명중률 **50%**(리프트 사용 후 2초 25%). 거리 멀수록 추가 감소.
- **토스터**: 실제 3×3 펠릿 Spherecast, 맞은 펠릿 각각 60% 확률 통과·펠릿당 8뎀(리프트 25%). 원거리(40+) 3단 차징(상대에게 토스트 표시, 사거리 264).
- 사격 연출·총소리·재장전음(마커 기반)·이펙트 전부 플레이어와 동일 broadcast.

## 투척·수류탄

- `GrenadeCore` 공용 모듈(플레이어 Cup/CAN과 동일 소스): 레이캐스트 포물선·유리벽 관통·파편·장판 DOT·슬로우·폭발·사운드.
- **투척무기 1종 고정**(스폰 시 BotThrow — 플레이어 로드아웃 공정성). **자폭 고려**: CAN(반경20) 봇은 대상 26 미만 투척 보류.
- **투척 시퀀스**: 총 내림 → 수류탄 들기 → 0.35초 후 투척 → 0.7초 총 복귀(그동안 사격 금지).
- **근거 기반**: 자기 연막엔 안 던짐(적이 안에 들어오면 예외), 적이 연막 안·방금 터진 적 연막일 때만.
- **엄폐 투척 + 푸시**: 락온 대상이 엄폐로 0.4초 시야 상실 시 투척 → 3.5초 강푸시(거점+40까지).

## 이동·맵 활용

- **거점 최우선**: 장판 회피 > 거점 진입 > 락온 추격(거점+15) > 거점 내 로밍(존버 금지·적 수색).
- **Y축 고지 활용(48차)**: 거점+82 내 수직연결 상단(양쪽 건물 리프트·사다리·점프대)을 VANTAGES로 수집. 로밍 시 역할별 확률로 선점(스나이퍼 65%·기타 40%)하고, **스나이퍼는 전투 중에도** 저지대·원거리 교전이면 근처(<62) 고지 중 대상 시야 확보되는 곳으로 등반해 그 위에서 교전(10~14초 점거 후 쿨다운). 코앞 러시엔 등반 안 함(소극화 방지).
- **학습 루트**: 거점 진입 시 60% 확률로 사람 동선(RouteLibrary) 재생, 40% 탐험. → [FEAT-0028](./FEAT-0028-ai-telemetry-learning.md). ※ 49차 확인 결과 저장 루트가 전부 플레이어·중앙 쏠림이라 분산 효과는 약함 — 분산은 아래 절차적 방식이 담당.
- **측면/건물 경유 접근 분산(49차)**: 중앙 단일 동선 쏠림·뭉침 해소. 거점을 둘러싼 스테이징 지점(사다리·리프트 등 건물 입구 + 8방위 측면점)을 만들어, 접근 중(거점 55+ 거리) 봇마다 다른 지점을 경유해 진입(학습 루트보다 우선, 거점 근접 시 무시로 진입 지연 최소화). 검증: 접근 방위 8/8 점유·봇 간 평균 최근접 76스터드.
- **맵 상호작용**: 문 열기(hinge 트윈), 유리벽 파괴, Rope 집라인, 사다리·리프트·점프대 수직 우회(정체 시 블랙리스트), 소화기 사격(연막 생성), 에너지드링크 획득.
- **스폰**: 모든 플레이어·봇으로부터 최소거리 최대인 지점(몰림 방지).

## 아이템·능력·회복

- 기본 소지 플레이어 동일: 수류탄 2 + 책 3.
- **회복**: 5초 무피격 시 HP 재생(8/s). 쉴드는 책 힐 세션(플레이어 완전 동일 — 무기 홀스터·r15 book 리그·힐 애니·지퍼 소리·0.9초당 +25·힐 중 사격 금지·걷기).
- **에너지드링크 능력 풀버전**: 랜덤 3종(무한탄창·무한수류탄·은신) + 이속, 10초.
- 사망 시 책 드롭, 바닥 책 루팅.

## 멈블 음성 (28차)

`SFX > Clean UP crew` 폴더 기반, 봇당 음성 큐(끝까지 재생·겹침 금지·과밀 스킵). Aggro(느낌표)·Kill(킬)·Roming(거점 두리번)·Grenade(투척, 1순위).

## 리깅·사운드

- 3인칭 무기 리그·애니 전 무기 동일(WeaponRig3P + ThirdPerson + pose 스위처 + Tilt).
- 발소리·달리기 소리 속도 기반(플레이어 동일), 사망 시 정지.
- 봇 처치 시 킬러캠(DeathCam killerBot), 봇 킬 점수(기본20·거점50·연속30).

## 개선 이력 요약

10~21차: 인지 파이프라인·피격 반격·연막 룰·아이템·리깅·CAN/Cup 리깅 동등화.
22~26차: 문·로프·전투이동·최원거리 스폰·토스터 차징·소화기 사격·루트 다양화.
27~33차: 수류탄 GrenadeCore 통합·멈블·능력 풀버전·거점 점수 우선·연막 인식 수정·명중률·토스터 펠릿.
34~41차: 로프 끼임·동선 학습(RouteLibrary)·힐 동일화·투척 시퀀스·엄폐 투척·회복 버그·사다리 끝 수정.
42차: **무기 성향 + mood — 능동 전투 다중화**.
43·44차: 사다리 등반 수정(트러스 중심 접근), 피격 반격(사거리 무관 — 유효 데미지면 반격 / 아니면 엄폐 접근).
45~47차: 끼임 최소화(직선 지름길·unstuck 넛지), 거점 직행(진입 중 딴짓 제거), 로밍 시 Y축 고지 선점.
48차: **전투 중 고지 선점 — 스나이퍼가 교전 중에도 양쪽 건물로 등반**, 고지 후보 반경 82로 확대(사다리 실사용).
49차: **측면/건물 경유 접근 분산 — 중앙 쏠림·뭉침 해소**(스테이징 레인 배정). 학습 데이터 점검으로 "저장 루트=플레이어·중앙 쏠림 → 학습 분산 불가" 확인.
