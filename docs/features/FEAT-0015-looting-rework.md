# FEAT-0015 — 루팅 시스템 개편 (책 드롭 · 근접 흡수)

| 항목 | 값 |
| --- | --- |
| 상태 | 완료 · 반경 튜닝 여지 |
| 관련 시스템 | 힐/쉴드(책), 사망 처리 |
| 구현 위치 | `ServerScriptService.HealHandler` |
| 날짜 | 2026-08-01 |

## 개요

쉴드템(책)의 사망 드롭과 획득 방식을 정리했다. 죽으면 보유 책이 소닉 링처럼 흩뿌려지고, 다른 플레이어가 다가가면 몬스터 캔과 동일한 근접 방식으로 자동 획득한다.

## 사망 드롭

사망 시 `dropBooks(pos, count)`가 파란 네온 구슬(`ShieldBookDrop`)을 튕겨 흩뿌린다.

- 드롭 수 = **사망 시 보유 책 개수**(안전상 내부 최대 12개 캡).
- 각 구슬은 무작위 방향 초기 속도 + 회전, `PointLight` 부착, 20초 후 소멸(`Debris`).

## 근접 흡수 (몬스터 캔 방식)

자석처럼 끌어당기거나 킬한 사람에게 우선 지급하는 방식은 **쓰지 않는다**. 몬스터 에너지 픽업과 동일하게, 0.1초 주기 루프가 각 구슬을 훑어 반경 안 플레이어에게 지급한다.

- `BOOK_PICKUP_RADIUS`(기본 5스터드) 안에 들어온 **살아있는** 플레이어가
- 책 여유(`BookCount < BOOK_MAX`)가 있으면 획득 + `item_pickup` 사운드.
- 죽자마자 즉시 먹히지 않도록 드롭 후 **0.6초 픽업 딜레이**.
- 책이 가득(`BOOK_MAX=5`)이면 못 줍고 바닥에 남아 소멸까지 대기.

## 관련 상수 (`HealHandler` 상단)

| 상수 | 기본값 | 의미 |
| --- | --- | --- |
| `BOOK_MAX` | 5 | 플레이어 최대 보유 책 수 |
| `BOOK_START` | 3 | 리스폰 시 지급 책 수 |
| `BOOK_PICKUP_RADIUS` | 5 | 근접 획득 반경(stud) |

## 설계 메모

- 킬러 우선 지급/자석 흡수를 한 번 시도했다가, 아이템(몬스터 캔)과 동작을 통일하기 위해 근접 픽업으로 되돌렸다. 구슬을 끌어오지 않으므로 지형 걸림·튀는 문제도 없다.
- 힐 자체는 [힐/쉴드 시스템](./FEAT-0012-sound-system.md)이 아니라 서버 권위 `HealHandler`가 `BookCount` 어트리뷰트로 관리한다(틱당 쉴드 25 회복, 책 1권 소모).

## 변경 로그

- 2026-08-01: 사망 드롭(보유 개수만큼) + 근접 흡수(반경 5, 몬스터 캔 방식) 정리. 초기 고정 2개 드롭·자석 흡수 시안은 폐기.
