# FEAT-0028 — AI 동선 텔레메트리 + 학습 (RouteLibrary)

| 항목 | 값 |
| --- | --- |
| 상태 | 구현 · 라이브 수집 중 · 이동 학습 2차(v3) |
| 구현 위치 | `ServerScriptService.AIMovementTelemetry` (수집), `ServerStorage.RouteLibrary` (학습 결과), `BotManager` (봇 연결) |
| 저장소 | DataStore `AIMovement_v1` (클라우드, 실험 단위) |
| 전제 | Game Settings → 보안 → Studio API 서비스 접근 허용 |

> 세부 경위는 [ai-log 2026-08-08](../ai-log/2026-08-08.md) 13·20·23번, [2026-08-10](../ai-log/2026-08-10.md) 6번. 봇 본체는 [FEAT-0027](./FEAT-0027-ai-bot-system.md).

## 왜 넣는가

봇 동선을 감이 아니라 **데이터로** 개선하고, 실제 플레이어의 좋은 동선을 봇이 재생(모방)하게 한다. 지금 버전 행동은 건드리지 않고 **관측 → 분석 → 반영**의 배치 사이클을 돌린다.

## 수집 (관측 전용)

`AIMovementTelemetry`가 매치 중 기록(봇 행동에 영향 없음):

- **위치 샘플** 0.5초: 봇·참가 플레이어의 좌표/속도/거점내/교전 여부(최근 1.2만).
- **사망 지점**: 좌표.
- **플레이어 진입 루트**: 이동 중 0.7초 웨이포인트, 거점 도달 시 1개 루트로 확정.
- `workspace.TelemetryOn=false`로 끔.

## 클라우드 저장 (DataStore)

- 매치 종료·서버 종료 시 요약본(히트맵 16셀·사망·루트·봇 통계·점수)을 `AIMovement_v1`에 저장. `index` 키로 최근 60세션 관리.
- **Studio는 기본 쓰기 금지**(읽기 전용, 라이브 오염 방지). 검증 시에만 `workspace.TelemetryStudioWrite=true`.
- 샘플 20개 미만 세션은 저장 안 함(빈 서버 노이즈 컷).
- **게시 후에는 개발자 PC 상태와 무관하게 클라우드에 자동 축적**. 컴퓨터가 필요한 건 분석·반영 단계뿐.

## 학습 (이동 — RouteLibrary)

주기적으로 데이터를 읽어 사람 진입 루트를 추출·검증해 `ServerStorage.RouteLibrary`(ModuleScript)로 저장.

**품질 게이트**: 진입 완주 + 길이 30+ + 우회율 <2.2 + 끝점 거점(+10) 내 + **수직 등반(Y>8) 없음**(사다리 낀 루트 배제). 시작 셀(24스터드) 버킷당 최소 우회율. 대부분 고득점자의 저우회 동선이 자동 채택된다.

**봇 연결**(BotManager): 거점 진입 시 60% 확률로 시작점 35 내 학습 루트를 웨이포인트 재생, 40%는 기존 로직(탐험). 웨이포인트 7 도달 시 다음, 6초 정체 시 스킵, 30초 만료. `workspace.UseLearnedRoutes=false`로 즉시 끔(수제 로직 보존 = 롤백 0초).

## 퇴화·단일화 방지 (설계 원칙)

- **수제 로직이 기준선(baseline)** — 학습은 그 위에 얹는 옵션이지 대체가 아님. 토글로 즉시 되돌림.
- **단방향 품질 게이트** — 검증 통과분만 등록. 나쁜 동선은 애초에 안 배움.
- **ε-greedy 탐험(40%)** + 유사 루트 중복 제거 → 패턴 단일화 방지.
- **버전 관리**(v1→v2→v3) — 지표(점유율·점수)가 나빠지면 롤백.

## 이력

- v1(16세션): 진입 루트 171개 → 통과 2개. 로프 끼임 지점 발견·수정(정체율 74%→30%).
- v3(30세션): 루트 391개 → 수직 등반 제외 게이트 추가 → 통과 10개, 6개 시작 구역 커버. 봇 최고점 Alpha 788(사람 858 근접).
- 시각화: DataStore를 탑다운 2D 뷰어(히트맵·사망·루트 재생)로 확인. **B 스폰발 루트 0개**(표본 부족) 발견.

## 남은 것 / 다음

- **행동 패턴 학습**: 교전 스냅샷(상황→행동→결과) 수집 → 통계 기반 파라미터 보정. 재미 필터(고득점·이긴 교전만) 필수.
- 루트별 성과 추적·가중치·저성과 자동 강등(현재는 우회율 프록시).
- B 스폰 학습 루트 확보.
