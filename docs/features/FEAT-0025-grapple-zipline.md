# FEAT-0025 — 그래플 집라인 (Rope_act)

| 항목 | 값 |
| --- | --- |
| 상태 | 구현 · 라이브 검증 권장 |
| 관련 시스템 | 이동(GrappleController) / 맵 Rope_act |
| 작성일 | 2026-08-04 |

## 개요

맵에 배치된 `Rope_act`(기울어진 트러스 빔)를 **집라인처럼 타고 이동**하는 이동기. 에이펙스식 그래플을 참고하되, 임의 지점으로 날아가는 방식이 아니라 **빔의 끝에서 끝으로 이어지는 정해진 동선**을 자연스럽게 타는 형태다.

## 동작

- **프롬프트**: `Rope_act` 빔 전체에 걸쳐 `[E]` 프롬프트가 여러 개(빔을 따라 일정 간격) 떠서, 빔 근처 어디서든 잡을 수 있다.
- **탑승 동선**: 빔의 긴 축(트러스 `CFrame.UpVector`) 기준 양 끝점을 계산하고, 현재 위치를 빔에 **투영한 지점 → 먼 쪽 끝점**까지 이동한다. 천장·월드 Y를 임의로 조정하지 않고 **오직 Rope_act의 기울기 동선만** 따른다.
- **자연스러운 이동**: `E`를 눌러도 텔레포트하지 않는다. `LinearVelocity`로 부드럽게 끌어붙여 타기 시작(JOIN)하고, 일정 속도(MOVE_SPEED≈40)로 끝점까지 라이드. 빔과 살짝 간격(HANG_OFFSET)을 두고 매달린 자세.
- **하차**: 타는 도중 **스페이스바**로 즉시 내릴 수 있다(유리벽 파괴의 SPACE 프롬프트와 유사한 조작감).
- **전투 병행**: 그래플 중에도 **총·수류탄 사용 가능**(카메라를 향하도록 몸 방향 고정). 단 **힐은 불가**(`Grappling` 어트리뷰트로 차단).

## 관련 변경

- 로프 비주얼(빔에 그리던 시각 로프) 제거 — 불필요.
- 프롬프트 잡히는 범위 축소(초기엔 너무 넓게 잡히던 것 → 빔 근처로 제한).
- 무한수류탄(InfiniteGrenade) 상태에서도 그래플 정상 탑승.

## 구현 위치

- `StarterPlayer.StarterPlayerScripts.GrappleController`(신설) — 빔 탐색·끝점 계산·라이드·프롬프트·하차
- `StarterPlayer.StarterPlayerScripts.HealController` — `Grappling` 중 힐 차단
- 맵 `Workspace`의 `Rope_act`(TrussPart) — 동선 소스

## 미구현 / 추후

- 3인칭 매달림 포즈·연출은 추후 다듬기.

## 변경 로그

- 2026-08-04: Rope_act 끝-끝 집라인 라이드 + [E] 프롬프트(빔 전체) + 스페이스 하차 + 전투 병행(힐 제외) + 텔레포트 없는 부드러운 탑승.
