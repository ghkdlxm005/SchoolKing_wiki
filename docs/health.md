# 체력 · 실드

<div className="sk-stat">
  <div><b>100</b><span>체력</span></div>
  <div><b>100</b><span>실드</span></div>
  <div><b>10/초</b><span>체력 자동 회복</span></div>
  <div><b>5초</b><span>부활 무적</span></div>
</div>

| 항목 | 내용 |
| --- | --- |
| 피해 순서 | 실드가 먼저 깎이고, 남은 피해가 체력으로 넘어갑니다 |
| 실드 회복 | **자연 회복 없음.** [책](./items/book.md), 왕관 보유자의 처치 보상으로만 회복 |
| 체력 회복 | 마지막으로 피해를 받고 **3초 후부터 초당 10** |
| 부활 무적 | 부활 후 5초 (왕관 뺏기) |
| 왕관 보유자 | 최대 체력 125 |

- 왕관 뺏기에서는 리프트 · 집라인 · 그래플을 타는 동안 자동 회복이 멈추고, 내린 뒤 3초 후 다시 시작합니다.

## 헤드샷
| 무기 | 머리 | 팔다리 |
| --- | --- | --- |
| 목발 · 컴퍼스 | ×1.5 | ×0.7 |
| 토스터 | ×1.5 | ×0.8 |
| 스나이퍼 | ×1.2 | ×1.0 |
| 실리콘건 · 근접 · 투척물 | 헤드샷 없음 | — |

## 화면 표시
- 피해 숫자: 헤드샷은 노란색, 처치한 막타는 빨간색. 연속으로 맞히면 누적 숫자가 커졌다 돌아옵니다.
- 적은 흰 외곽선으로 표시됩니다(벽에 가리면 안 보임). 은신 중이거나 연막 너머면 안 보입니다.
- 실드가 없을 때 맞으면 피격 이펙트가 진해지고, 머리에 맞으면 빨간색입니다.


## 적용 예정: 자동 회복 표시 개선

왕관 뺏기와 테니스에서 자동 체력 회복 중 초록색 테두리가 표시됩니다. 소량을 한 번에 모두 회복해도 잠깐 표시한 뒤 사라지며, 다시 맞으면 빨간 피격 효과로 전환됩니다. 메뉴·사망·관전·결과 연출 중에는 숨깁니다. 회복 수치와 이동 장치 이용 중 회복 제한은 유지합니다.

게임 반영 시점은 추후 안내합니다. [자세한 변경점](/patch-notes/2026-10-26-healing-border)
