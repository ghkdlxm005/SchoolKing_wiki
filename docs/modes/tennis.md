# 1대1 · 테니스장

테니스 코트에서 벌이는 1대1 라운드제 결투입니다. 상대를 처치하면 라운드를 가져가고, **먼저 5라운드를 이기면** 승리합니다.

## 라운드 흐름
1. 양쪽 스폰 지점에 고정
2. **무기 선택** 10초 (둘 다 준비하면 바로). 준비한 뒤에는 그 라운드 동안 못 바꿉니다.
3. 3초 카운트다운 → 전투 (고른 주무기를 자동으로 듦)
4. 상대를 처치하면 1점. 0.12초 안에 둘 다 죽으면 무승부(점수 없음)
5. 라운드 결과 6.5초 → 다음 라운드

## 매 라운드 초기화
- 체력 · 실드 100, 책 3권, 투척물 2개
- 이전 라운드의 바닥 장판 · 투사체 제거
- 선택 시간 · 카운트다운 · 결과 화면 중에는 피해를 받지 않습니다.

## 연출
- 처치 순간 **3초 슬로 모션** (10% 속도에서 점점 원래 속도로)
- 체력 35% 이하이면 화면 테두리가 붉게, 자동 회복 중에는 초록색으로 표시
- 처치 시 관중 반응과 축하 연출

## 경기 종료 · 재대결
- 결과 연출 후 8초 뒤 **재대결** 창이 열립니다. 15초 안에 둘 다 누르면 바로 새 경기.
- 경기 중 나가면 상대 승리(기권).
- 코트 밖으로 밀려나면 잠시 후 마지막 안전 위치로 돌아옵니다.

## 다른 점 (왕관 뺏기와 비교)
- 죽어도 책이 떨어지지 않습니다.
- 에너지 드링크 · 왕관이 없습니다.

### 적용 예정: 점프·착지 규칙

연습 상대도 연속 점프 시 높이가 줄고, 착지 후0.75초 동안 원래 높이로 회복됩니다. 높은 곳에서 떨어진 뒤에는 잠시 이동이 느려졌다가 회복됩니다. 게임 반영 시점은 추후 안내합니다.

### 적용 예정: 엄폐물 등반

연습 상대가 중앙·측면 엄폐물 위의 적을 추적할 때 점프와 벽 오르기로 접근하고, 턱을 넘어 올라옵니다. 진입·착지 공간이 막힌 곳은 피하며, 등반 중에는 사격을 멈춥니다. 게임 반영 시점은 추후 안내합니다.

### 적용 예정: 기본 벽점프

연습 상대가 가까운 엄폐물을 박차고 기존 이동 목표 방향으로 이동합니다. 이동·착지 공간을 확인해 사용하고, 플레이어와 같은 벽점프 효과음이 들립니다. 게임 반영 시점은 추후 안내합니다.
