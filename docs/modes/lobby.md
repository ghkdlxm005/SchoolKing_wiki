# 로비

:::info 테스트 중
로비 기능은 시험 중이라 바뀔 수 있습니다.
:::

## 모드 선택
| 선택 | 내용 |
| --- | --- |
| 왕관 뺏기 PvP | 2~4명. 10초가 지나도 인원이 모자라면 있는 인원으로 시작 |
| 왕관 뺏기 AI | 빈자리를 봇이 채움 |
| 1대1 PvP | 2명. 2인 파티로 고르면 파티원끼리 대결 |
| 1대1 AI | 혼자만 입장 |

- 경기를 찾으면 **10초 안에 수락**해야 합니다. 120초 동안 못 찾으면 검색이 끝납니다.
- 경기가 끝나면 로비로 돌아오고, 파티는 유지됩니다.
- 경기장에서 <kbd>F6</kbd>으로 로비로 돌아갈 수 있습니다.

## 파티
- 최대 4명. 같은 로비의 플레이어를 초대 · 수락 · 거절.
- 파티장만 모드와 관전을 고르고, 파티원을 내보낼 수 있습니다.
- 매칭 · 이동 중에는 파티를 바꿀 수 없습니다.

## 관전
- 진행 중인 경기 목록에서 골라 관전 전용으로 들어갑니다. 경기당 최대 8명.
- 관전 조작은 [조작키](../controls.md#관전-중)를 참고하세요.
