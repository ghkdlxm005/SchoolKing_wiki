# AI 대전

로비에서 대전 방식을 **AI**로 고르면 봇과 대결합니다. 규칙은 각 모드와 같고, 봇도 플레이어와 같은 무기 · 규칙을 사용합니다.

## 왕관 뺏기 AI전
- 빈자리(총 4명까지)를 봇이 자동으로 채웁니다.
- 봇: 체력 100, 실드 100. 무기는 목발 · 컴퍼스 · 실리콘건 · 토스터 중 하나.
- 사다리 · 건물을 활용하고, 반격하고, 수류탄을 쓰고, 왕관을 노립니다.
- 죽으면 3.5초 뒤 다시 나옵니다.

PvP 경기에서도 무기 선택 화면의 **봇 채우기** 버튼으로 빈자리를 채울 수 있습니다.

## 1대1 AI전 — CleanUP Alpha
| 항목 | 값 |
| --- | --- |
| 입장 | 혼자일 때만 |
| 체력 / 실드 | 100 / **150** |
| 무기 | 목발 · 컴퍼스 · 실리콘건 · 토스터 중 무작위 |
| 특징 | 책으로 실드를 회복합니다 |
