# 맵

## 체육관 경기장 (왕관 뺏기)
| 요소 | 내용 |
| --- | --- |
| 중앙 거점 | 맵 중앙의 구역. 왕관 보유자는 여기서 멀리 벗어나면 왕관을 놓칩니다 |
| 왕관 자리 | 맵 중앙 상단(3층). 경기 시작 · 왕관 복귀 시 이 자리 |
| 관중석 | 처치가 나오면 관중이 환호합니다 |
| 문 | 클릭해서 여닫는 양문형 금속문, <kbd>E</kbd>로 여는 문 |
| 유리벽 | 깨지는 유리벽 여러 개 |
| 소화기 | 부수면 연막 → [소화기 · 연막](./items/extinguisher.md) |
| 집라인 | 기울어진 로프 2개 |
| 리프트 · 점프대 | 층 사이 이동 장치 → [이동](./movement.md#맵-이동-장치-왕관-뺏기) |
| 에너지 드링크 | → [에너지 드링크](./items/energy-drink.md) |

## 테니스장 (1대1)
| 요소 | 내용 |
| --- | --- |
| 테니스 코트 | 1대1 전투 구역. 양쪽에 스폰 지점이 있고, 코트 밖으로 밀려나면 되돌아옵니다 |
| 관중석 | 처치 · 승리 때 관중 반응과 축하 연출 |
