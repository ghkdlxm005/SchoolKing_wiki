# BUG-0022 — 캔 폭발이 벽을 통과해 데미지

| 항목 | 값 |
| --- | --- |
| 상태 | fixed (라이브 재검증 필요) |
| 심각도 | medium |
| 관련 시스템 | 투척류(CAN) 폭발 데미지 |
| 발견일 | 2026-08-04 |

## 증상

캔(CAN)이 폭발할 때, 폭발 지점과 대상 사이에 벽이 있어도 데미지가 그대로 들어갔다. 벽 뒤에 숨어 있어도 폭발 반경 안이면 피격되는 문제.

## 원인

폭발 데미지 함수가 **폭발 중심과 대상의 거리만** 검사하고, 사이에 장애물이 있는지(시야, LOS)는 확인하지 않았다. `dist <= ExplosionRadius`이면 무조건 데미지·넉백을 적용했다.

## 조치

폭발 데미지 적용 전에 **폭발점 → 대상 레이캐스트**로 차폐를 검사한다.

- 폭발 중심에서 대상 몸체까지 레이를 쏴, 도중에 솔리드 파트가 있으면 데미지를 건너뛴다.
- 대상 모델과 시전자는 필터에서 제외한다.
- 유리벽(`GlassWrapped`)은 어차피 폭발/투척으로 깨지고 통과되는 오브젝트라 **차폐로 보지 않고 관통 허용**한다.

## 결과

벽 뒤 대상은 더 이상 폭발 피해를 받지 않는다. 같은 공간(시야 확보) 대상만 정상 피격. **라이브 재검증 권장.**

## 구현 위치

- `StarterPack.CAN.ServerHandler` — 폭발 `damage(model)` 내 LOS 레이캐스트 추가
