# BUG-0023 — 실리콘건 레이저 잔상 잔존

| 항목 | 값 |
| --- | --- |
| 상태 | fixed (라이브 재검증 필요) |
| 심각도 | high |
| 관련 시스템 | 실리콘건 상대 시점 레이저(서버 빔) |
| 발견일 | 2026-08-04 |

## 증상

실리콘건을 쏘면 레이저 빔 잔상이 화면에 계속 남고, 발사를 멈춰도 사라지지 않았다.

## 원인

상대 시점에서도 레이저가 보이도록 추가한 **서버 빔 파트**가 발사 틱마다 새로 생성됐다. 재사용을 위해 `tool:FindFirstChild("__ServerLaser")`로 기존 빔을 찾았지만, 실제 빔은 `workspace`에 두었기 때문에 매 틱 조회가 실패 → **틱마다 새 파트가 계속 쌓였다.** 숨김 처리는 최신 세션 하나만 적용돼, 이전 틱들의 빔은 불투명(보이는) 상태로 영구히 남았다.

## 조치

- 빔 인스턴스를 `state.__laserBeam`에 저장해 **하나만 재사용**한다(없거나 파괴됐을 때만 새로 생성).
- 발사 정지 후 0.15초가 지나면 빔을 투명 처리(다음 틱이 없으면 사라짐).
- 무기 장착 해제(`Unequipped`) 시 빔을 즉시 제거한다.

## 결과

Studio Play 검증: 10틱 연속 발사 중 빔은 **1개만 유지**됐고, 발사 정지 0.6초 후 그 1개가 숨김 처리(보이는 개수 0). 수정 전이라면 10개가 지워지지 않고 남았을 상황. **라이브 재검증 권장.**

## 구현 위치

- `StarterPack.SiliconGun.ServerHandler` — 서버 레이저 빔 생성/재사용 + Unequipped 정리

## 관련

- 상대 시점 레이저 가시화는 [SiliconGun 개선](../changelog.md) 참고.
