# 조작키 (PC)

## 전투
| 키 | 동작 |
| --- | --- |
| 좌클릭 | 발사 · 휘두르기 · 누르고 있다가 놓아 투척 · 그래플 발사 / 해제 |
| 우클릭 | 조준 (누르는 동안). 스나이퍼는 스코프 켜기 / 끄기, 토스터는 차지 |
| 마우스 휠 | 스나이퍼 스코프 배율 (1~4배) |
| <kbd>R</kbd> | 재장전. 스나이퍼는 0.4초 이상 눌러 탄 합치기 |
| <kbd>V</kbd> | 근접 공격 (토스터 · 실리콘건 · 스나이퍼) |
| <kbd>1</kbd> | 주무기 |
| <kbd>3</kbd> | 쓰레받이 |
| <kbd>G</kbd> | 투척 무기 / 그래플링 훅 |
| <kbd>4</kbd> | 책으로 실드 회복 시작 / 중단 |

## 이동
| 키 | 동작 |
| --- | --- |
| <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> | 이동 |
| <kbd>Shift</kbd> | 달리기 켜기 / 끄기 (책 사용 중이면 취소) |
| <kbd>Ctrl</kbd> | 앉기 · 달리는 중 슬라이드 |
| <kbd>Space</kbd> | 점프 · 슬라이드 점프 · 벽 점프 · 턱 넘기 부스트 · 유리벽 깨기 · 집라인에서 내리기 |
| <kbd>E</kbd> | 집라인 타기 |

## 메뉴
| 키 | 동작 |
| --- | --- |
| <kbd>Tab</kbd> | 무기 선택 창 (왕관 뺏기, 사망 중) |
| <kbd>Space</kbd> (사망 중) | 사망 2초 후부터 바로 부활 |
| <kbd>Esc</kbd> | 옵션 |
| <kbd>F6</kbd> | 로비로 돌아가기 |

## 관전 중
| 키 | 동작 |
| --- | --- |
| <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> | 이동 |
| <kbd>E</kbd> / <kbd>Space</kbd> | 위로 |
| <kbd>Q</kbd> / <kbd>Ctrl</kbd> | 아래로 |
| <kbd>Shift</kbd> | 3배 빠르게 |
| <kbd>[</kbd> / <kbd>]</kbd> | 이동 속도 단계 조절 |
| <kbd>Alt</kbd> (누르는 동안) | 마우스 커서 풀기 |
| <kbd>\</kbd> | 화면 UI 숨기기 / 보이기 |

## 모바일
화면 버튼(발사 · 조준 · 달리기 · 슬라이드 · 투척 등)을 지원합니다. 무기 선택 화면에서 무기 카드의 **i** 버튼을 누르면 상세 정보가 나옵니다.
