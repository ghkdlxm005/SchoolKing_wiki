# 토스터

**샷건.** 한 발에 펠릿 8개가 세로 8자 모양으로 퍼집니다. 우클릭으로 **차지**하면 탄이 모이고, 완충 사격을 많이 맞히면 상대 실드를 태웁니다.

| 항목 | 값 |
| --- | --- |
| 발사 방식 | 자동 (누르고 있으면 연사) |
| 펠릿당 머리 / 팔다리 | 12 / 6.4 |
| 거리 감소 | 없음 (사거리 120 안에서는 그대로) |
| 근접 공격 (V) | 있음 (피해 40) |

## 3단계 차지
- 우클릭을 누르고 있으면 차지됩니다. 1단계 → 약 0.5초에 2단계 → **1.25초에 완충**.
- 단계가 오를수록 산탄이 좁아집니다(완충 시 기본 폭의 60%).
- 우클릭을 놓으면 약 0.5초에 걸쳐 차지가 사라지고, 쏘면 0으로 돌아갑니다.

## 화상
- **완충 사격**으로 한 상대에게 펠릿 **3개 이상** 맞히면 화상: 3초 동안 초당 6 피해.
- 화상은 **실드에만** 들어가고 체력으로 넘어가지 않습니다. 실드가 0이 되면 바로 꺼집니다.
- 다시 걸면 시간만 새로 시작합니다(겹치지 않음).
