# 목발

**자동 소총 · 기본 무기.** 무기를 고르지 않으면 목발이 지급됩니다. 누르고 있으면 계속 나가는 연사형으로, 거리를 가리지 않고 무난하게 쓰기 좋습니다.

| 항목 | 값 |
| --- | --- |
| 발사 방식 | 자동 (누르고 있으면 연사) |
| 팔다리 피해 | 10.5 |
| 거리 감소 | 80 stud부터 줄어 450에서 40% |
| 조준 | 약 1.8배 확대, 탄 퍼짐 ×0.25 |
| 근접 공격 (V) | 없음 |

## 팁
- 조준하면 탄이 매우 모이므로 중거리에서는 조준 사격이 유리합니다.
- 반동이 연사할수록 조금씩 쌓입니다. 짧게 끊어 쏘면 더 정확합니다.


## 적용 예정 사격 개선

지상 비견착 첫 3발은 반동을 유지하면서 추가 탄퍼짐 없이 발사됩니다. 이후 연사할수록 퍼짐이 증가하고, 마지막 발사 0.3초 뒤부터 회복해 0.65초에 초기 정확도가 돌아옵니다. 공중에서는 첫 3발 무확산이 적용되지 않습니다. 일정한 반동 흐름과 수평 추적 중 최대 30% 반동 완화도 추가됩니다.

목발은 연속 사격 12발째에 최대 탄퍼짐에 도달합니다. 견착 정확도는 유지합니다.
