# 목발

**자동 소총 · 기본 무기.** 무기를 고르지 않으면 목발이 지급됩니다. 누르고 있으면 계속 나가는 연사형으로, 거리를 가리지 않고 무난하게 쓰기 좋습니다.

| 항목 | 값 |
| --- | --- |
| 발사 방식 | 자동 (누르고 있으면 연사) |
| 팔다리 피해 | 10.5 |
| 거리 감소 | 80 stud부터 줄어 450에서 40% |
| 조준 | 약 1.8배 확대, 탄 퍼짐 ×0.25 |
| 근접 공격 (V) | 없음 |

## 팁
- 조준하면 탄이 매우 모이므로 중거리에서는 조준 사격이 유리합니다.
- 반동이 연사할수록 조금씩 쌓입니다. 짧게 끊어 쏘면 더 정확합니다.
