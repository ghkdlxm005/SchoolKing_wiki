# 실리콘건

**레이저.** 누르고 있으면 레이저가 계속 나가고, 오래 맞힐수록 피해가 올라갑니다. 탄 퍼짐이 없고 맞은 상대는 잠깐 느려집니다.

<div className="sk-stat">
  <div><b>7 → 11</b><span>틱당 피해</span></div>
  <div><b>10틱/초</b><span>조사 속도</span></div>
  <div><b>2.3초</b><span>최대 피해까지</span></div>
  <div><b>50 / 200</b><span>탄창 / 예비</span></div>
  <div><b>1.8초</b><span>재장전</span></div>
  <div><b>500</b><span>최대 사거리</span></div>
</div>

| 항목 | 값 |
| --- | --- |
| 발사 방식 | 지속 조사 (1틱에 탄 1발, 탄창 50 = 약 5초) |
| 부위 | 머리 · 몸통 · 팔다리 피해 같음 (헤드샷 없음) |
| 감속 | 맞은 상대 0.5초 동안 이동 속도 −3 |
| 거리 감소 | 80 stud부터 줄어 500에서 40% |
| 유리벽 | 피해 2배 |
| 근접 공격 (V) | 있음 (피해 40) |

## 피해 상승
- 계속 맞히면 틱당 피해가 7에서 **11까지 2.3초**에 걸쳐 오릅니다.
- 쏘는 것을 멈추면 약 1초에 걸쳐 다시 내려갑니다.
- 80% 넘게 오르면 반동이 커집니다.
- 에너지 드링크 **무한 탄창** 중에는 처음부터 최대 피해(11).
