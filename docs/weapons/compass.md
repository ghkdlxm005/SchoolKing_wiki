# 컴퍼스

**3점사 소총.** 한 번 누르면 3발이 빠르게 나갑니다. 한 발 피해가 높아 점사가 모두 맞으면 순간 피해가 큽니다.

| 항목 | 값 |
| --- | --- |
| 발사 방식 | 3점사 (누르고 있으면 점사 반복, 초당 약 4회 = 약 12발) |
| 팔다리 피해 | 15.4 |
| 거리 감소 | 80 stud부터 줄어 400에서 40% |
| 조준 | 약 1.6배 확대, 탄 퍼짐 ×0.3 |
| 근접 공격 (V) | 없음 |

## 팁
- 점사 3발이 모두 머리에 맞으면 99. 실드가 없는 상대는 한 번에 거의 쓰러집니다.
- 예비탄이 350발로 넉넉합니다.
