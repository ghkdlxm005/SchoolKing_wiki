# 그래플링 훅

투척 무기 대신 고를 수 있는 이동 장비입니다. 벽 · 바닥에 걸어 빠르게 날아갑니다.

<div className="sk-stat">
  <div><b>85</b><span>연결 거리</span></div>
  <div><b>6초</b><span>최대 연결</span></div>
  <div><b>20초</b><span>재사용</span></div>
</div>

| 조작 | 동작 |
| --- | --- |
| <kbd>G</kbd> | 꺼내기 (든 상태에서 다시 누르면 집어넣기) |
| 좌클릭 | 발사 / 다시 누르면 해제 |
| 우클릭 | 해제 후 주무기로 전환 |

- 스윙하며 관성이 유지되고, 연결 직후 점프하면 더 높이 오릅니다. 착지하면 슬라이드로 이어집니다.
- 시선을 크게 돌리면 자동으로 풀립니다.
- 재사용 20초는 실제로 걸렸을 때만 돌고, 부활 · 라운드 종료 시 초기화됩니다.
- 사람 · 봇에는 걸리지 않습니다. 그래플 중에는 책을 쓸 수 없습니다.
