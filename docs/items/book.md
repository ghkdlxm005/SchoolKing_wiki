# 책 (실드 회복)

실드를 회복하는 유일한 소모품입니다. <kbd>4</kbd>로 사용합니다.

<div className="sk-stat">
  <div><b>+25</b><span>권당 실드</span></div>
  <div><b>약 0.9초</b><span>권당 시간</span></div>
  <div><b>3권</b><span>시작 개수</span></div>
  <div><b>5권</b><span>최대 보유</span></div>
</div>

- <kbd>4</kbd>를 누르면 시작, 다시 누르면 중단. 실드가 가득 차거나 책이 떨어질 때까지 계속 읽습니다.
- <kbd>Shift</kbd>(달리기)나 무기 전환(<kbd>1</kbd> <kbd>3</kbd> <kbd>G</kbd>)을 하면 취소됩니다.
- 실드가 가득 찼을 때, 그래플 · 집라인 · 리프트를 타는 중에는 쓸 수 없습니다.
- 부활 · 라운드마다 3권으로 맞춰집니다.
- **왕관 뺏기**: 죽으면 가진 책이 파란 구슬로 흩어집니다. 가까이 가면 1권씩 줍고, 20초 뒤 사라집니다. 5권이면 못 줍습니다.
- **테니스**: 책이 떨어지지 않습니다.
