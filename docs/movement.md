# 이동

| 동작 | 조작 | 내용 |
| --- | --- | --- |
| 걷기 | <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> | 속도 16 |
| 달리기 | <kbd>Shift</kbd> (켜기 / 끄기) | 속도 24, 1.5초에 걸쳐 가속. 맨손이면 +3 |
| 앉기 | <kbd>Ctrl</kbd> (누르는 동안) | 속도 8 |
| 슬라이드 | 달리는 중 <kbd>Ctrl</kbd> | 순간 최대 50으로 미끄러진 뒤 점점 느려짐. 내리막에서는 빨라짐. 공중에서 누르면 착지할 때 슬라이드 |
| 슬라이드 점프 | 슬라이드 중 <kbd>Space</kbd> | 슬라이드를 끊고 점프, 착지할 때 속도 80% 유지 |
| 벽 타기 | 공중에서 벽 쪽으로 이동 + <kbd>W</kbd> | 최대 3초 위로 오름. 키를 놓으면 천천히 미끄러짐. 벽을 따라 좌우 이동 가능 |
| 벽 점프 | 벽에 붙어 <kbd>Space</kbd> | 벽 반대쪽으로 비스듬히 튕겨 나감. 같은 벽에 바로 다시 붙지 않음 |
| 턱 넘기 + 부스트 | 턱 앞에서 <kbd>Space</kbd> | 낮은 턱을 자동으로 넘고, 넘는 순간 0.45초 안에 <kbd>Space</kbd>를 다시 누르면 입력 방향으로 강하게 튀어 나감 |

## 점프 피로
- 땅에서 연속으로 점프하면 높이가 최저 30%까지 줄어듭니다. 땅에 0.75초 있으면 완전히 회복.
- 벽 점프 직후 첫 점프도 낮아집니다.
- <kbd>Space</kbd>를 누르고 있어도 한 번만 점프합니다.

## 관성
공중에서는 방향 전환이 약하고 관성이 유지됩니다. 땅에서도 미끄러지듯 감속합니다.

## 총기 이동 모션 개선 예정

테니스와 왕관 뺏기에서 컴퍼스는 달릴 때 왼팔이 흔들리고, 목발·실리콘건·토스터는 출발·정지·좌우 이동에 맞춘 움직임을 보여 주도록 개선할 예정입니다. 이동 속도와 무기 성능은 유지됩니다. 자세한 내용은 [패치 노트](/patch-notes/2026-10-20-weapon-motion)를 참고하세요.

## 맵 이동 장치 (왕관 뺏기)
| 장치 | 조작 | 내용 |
| --- | --- | --- |
| **집라인** | 로프 근처에서 <kbd>E</kbd> | 로프를 따라 초당 40으로 이동. <kbd>Space</kbd>로 중간에 내림. 타는 중 무기 사용 가능, 책 사용 불가 |
| **리프트** | 위에 서기 | 꼭대기까지 올라간 뒤 최대 2초 머물고 앞으로 밀려남 |
| **점프대** | 밟기 | 경보가 두 번 울린 뒤(약 1초) 목표 지점으로 크게 날아감. 1.5초 후 다시 사용 가능 |
| **유리벽** | 근처에서 <kbd>Space</kbd> 또는 공격 | 체력 70. 깨지고 20초 후 서서히 다시 생김 |
