# 무기별 문서

무기 1종당 문서 1개. **각 문서 최상단 = 현재 스펙**(공격력·공격속도·탄창 등, GunConfig/MeleeConfig/GrenadeConfig 실값), **그 아래 = 수정 이력**(날짜별로 계속 추가).

값을 바꾸면 그 무기 문서의 "현재 스펙" 표를 갱신하고, "수정 이력"에 한 줄 추가한다.

## 무기 목록

| 무기 | 분류 | 핵심 |
| --- | --- | --- |
| [Compass](./compass.md) | 자동소총 | Dmg 22 · 연사 0.045s · 버스트 3 |
| [LegCrutch](./legcrutch.md) | 돌격소총(목발) | Dmg 18 · 탄창 27 · 재장전 1.2s |
| [SiliconGun](./silicongun.md) | 레이저건 | 램핑 6→12 · 피격 슬로우 · 창문 2배 |
| [Toaster](./toaster.md) | 샷건 | 3×3 펠릿 · 3단 차징 · 반자동 |
| [Dustpan](./dustpan.md) | 근접 | Dmg 50 · 돌진 · 넉백 |
| [Cup](./cup.md) | 수류탄(장판/DOT) | 틱 10 · 슬로우 15% |
| [CAN](./can.md) | 수류탄(폭발) | 95 · 반경 20 · 벽 차폐 |

> 집계 스냅샷(모든 무기 한 표)은 [설정값](../config-values.md)에도 있으나, **개별 무기 문서가 최신·정본**이다.
