# 패치 노트

플레이어 입장에서 달라진 점을 최신순으로 정리합니다. 테스트 빌드 기준이며, 실제 게시 버전과 다를 수 있습니다.

---

## 2026-10

### 신규 장비·무기
- **그래플링 훅** — 투척 슬롯 장비. 벽·바닥에 걸어 빠르게 이동하고, 시선을 돌리면 자동 해제. 연결 종료 후 20초 쿨다운, 부활·라운드 종료 시 초기화.
- **스나이퍼** — 우클릭 스코프(1~4배, 휠로 조절, 마지막 배율 기억), 볼트액션. 몸통·사지 75 / 머리 90, 캐릭터 관통(벽에서 멈춤).
- **스나이퍼 강화탄** — R을 길게 눌러 남은 탄을 한 발로 합침(2~5발, 피해 100~175). 합치는 동안 게이지 표시, 완료음과 강화 발사음 추가.

### 전투 피드백
- 처치 시 빨간 처치 마커, 헤드샷은 노란 피해 숫자, 처치한 막타는 빨간 숫자로 표시.
- 연속 명중 시 누적 피해 숫자가 커졌다 돌아오는 반응 추가.
- 실드 없는 상태의 피격 이펙트를 더 진하게, 머리 피격은 빨간색으로 구분.

### 탄약·HUD
- 잔탄이 절반 미만이면 주황, 10% 이하·마지막 1발이면 빨간색으로 깜빡임. 재장전 안내 문구 표시.
- 탄창이 비면 자동 재장전.
- 스나이퍼 스코프 중에도 체력·실드·아이템·탄약 HUD 표시.
- 무기·투척물 아이콘 이미지 교체.

### 테니스 (1v1)
- 처치 순간 3초 슬로모션(10% 속도에서 점차 정상 복귀).
- 체력 35% 이하일 때 화면 테두리가 붉게, 자동 회복 중에는 초록색으로 표시.
- 결과 화면·다시하기 동작 수정, 승리 연출 개선.

### 왕관 뺏기 (TGS)
- 플레이어·봇이 같은 자리에 스폰되던 문제 완화.

### 로비 (테스트 중)
- 모드 선택, 파티 초대, 진행 중인 경기 관전 기능 시험 중.

### 기타
- 처치 연출을 시험적으로 바꿨다가 기존 분해 연출로 되돌림.
- 맵에 쓰인 무료 모델에서 위험한 스크립트를 찾아 제거하는 보안 점검 실시.

## 2026-08
### 왕관 쟁탈
- **왕관(Crown)** 추가 — 획득하면 이동속도·최대 체력 증가, 머리 위 표시로 위치 공개, 왕관 보유자만 거점 점수 획득. 사망 시 그 자리에 떨어지고 일정 시간 후 원위치.
- 점수: 일반 처치 +20, 거점 처치 +30, 왕관 보유자의 거점 처치 +80, 왕관 보유자 처치(KING SLAYER) +150.
- 왕관을 쓴 본인 화면에서는 왕관이 시야를 가리지 않도록 반투명 처리.

### 모드·매칭
- 1인용 봇전 모드 추가.
- 서버 간 매칭, 매칭 수락 팝업, 라운드 시작 시 무기 선택(로드아웃) 화면 추가.
- 게임 종료 흐름(점수판 → 초기화 → 메인 화면) 정리, 재매칭 안 되던 문제 수정.

### 전투·무기
- 근접 무기 쓰레받이: 공격 3종 순환, 근접 돌진, 근접 무기 장착 시 이동속도 보너스.
- 킬 피드백 중앙 팝업, 처치 시 빨간 히트마커.
- 에너지 드링크 캔: 스폰 시 능력(무한 폭탄·무한 탄창·은신)이 정해지고 캔 모양으로 미리 표시.
- 모든 총알 궤적 표시, 무기 밸런스 여러 차례 조정, 재장전 중복 버그 수정.
- 감정표현(이모트) 메뉴 비활성화.

### 맵·상호작용
- 로프 집라인, 파괴 가능한 유리벽(스페이스로 파괴), 문·유리벽 상호작용.
- 연막 최적화(프레임 드랍 완화).

### 봇
- 봇의 이동·전투·거점 점령·왕관 대응을 크게 개선 (사다리·건물 활용, 반격, 캠핑 대응, 수류탄 활용 등). 봇은 플레이어와 같은 규칙·무기를 사용.
