테니스장과 왕관 뺏기의 컴퍼스 원거리 화력을 낮추고, 비견착 사격의 탄퍼짐과 반동을 늘립니다. 대신 탄창을 18발로 늘려 한 탄창에서 점사를 한 번 더 사용할 수 있도록 조정합니다.

<!-- truncate -->

> 적용 예정 변경입니다. 게임 반영 시점은 추후 안내합니다.

| 항목 | 이전 | 변경 |
| --- | --- | --- |
| 몸통 피해 | 22 | 18 |
| 머리 피해 배율 | 1.5배 | 1.4배 |
| 머리 피해 | 33 | 25.2 |
| 팔다리 피해 | 15.4 | 12.6 |
| 탄창 | 15발 | 18발 |
| 예비 탄약 | 350발 | 180발 |
| 비견착 탄퍼짐 | 기존 | 약 3.3배 |
| PC 첫 발 수직 반동 | 기존 | 비견착 1.5배 / 견착 2배 |
| 점사 안의 탄 간격 | 0.06초 | 0.08초 |
| 피해 감소 시작 거리 | 80스터드 | 60스터드 |
| 최대 거리 피해 비율 | 40% | 25% |

- 견착 탄퍼짐은 이전과 동일합니다. 정확도를 유지하려면 연속 사격 반동을 조절해야 합니다.
- 점사 묶음의 반복 주기, 최대 사거리 400스터드, 재장전 1.51초는 유지됩니다.
- 근거리 몸통 3점사 피해는 66에서 54로, 머리 3점사는 99에서 75.6으로 줄어듭니다.
- 최대 거리의 몸통 피해는 8.8에서 4.5로 줄어듭니다.
